DSA Patterns

  • HashMap / HashSet
    Frequency counting, two-sum variants, grouping. Pattern: trade space for O(1) lookup. Examples: anagram grouping, subarray with target sum.
  • Two Pointers
    Start+end pointers on sorted arrays, fast/slow pointers on linked lists. Examples: container with most water, cycle detection.
  • Sliding Window
    Fixed and variable-size windows on arrays/strings. Pattern: expand right, shrink left when constraint violated. Examples: longest substring without repeating characters.
  • Binary Search
    Search on sorted arrays, search on answer space. Examples: find minimum in rotated array, capacity to ship packages in D days.
  • Trees — DFS and BFS
    In-order, pre-order, post-order traversal. Level-order (BFS with queue). Examples: max depth, lowest common ancestor, right side view.
  • Linked Lists
    Reverse, detect cycle, merge sorted lists, find middle node. Pattern: dummy head node prevents edge cases.

SQL

  • Window Functions
    ROW_NUMBER, RANK, DENSE_RANK, LAG, LEAD, SUM OVER PARTITION. Used for ranking, running totals, and comparing rows without GROUP BY collapsing results.
  • CTEs and Recursive CTEs
    WITH clause for readable multi-step queries. Recursive CTEs for hierarchical data (org trees, folder structures). Much cleaner than nested subqueries.
  • GROUP BY and HAVING
    Aggregation with COUNT, SUM, AVG. HAVING filters aggregated groups (not WHERE). Grouping sets and ROLLUP for multi-level summaries.
  • Joins Deep Dive
    INNER, LEFT, RIGHT, FULL OUTER, CROSS JOIN. Self-joins for hierarchical comparisons. When each join type produces NULLs and why it matters.
  • Indexing and Query Performance
    Clustered vs non-clustered indexes. Covering indexes. Execution plans in SQL Server — when to use index scans vs seeks. Avoiding index-killing patterns (functions on columns).
